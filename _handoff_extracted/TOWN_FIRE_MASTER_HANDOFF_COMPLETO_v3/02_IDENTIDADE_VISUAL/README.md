# TOWN FIRE — Brand Assets Pack v1

Identidade-base: **TOWN FIRE — Engenharia de Conformidade Predial**

## Sistema visual
- Tipografia principal indicada pelo manual: **Montserrat**
- Tipografia secundária indicada pelo manual: **Poppins**
- Espresso: #2B1C14
- Rosa Queimado: #D4748C
- Rosa Blush: #F6D6DE
- Bege Latão: #D2B48C
- Pérgamo: #F5F2EC
- Carvão: #2D2D2D

## O que usar
- **Logo horizontal color-light**: padrão para fundo claro.
- **Logo horizontal color-dark**: para fundo escuro.
- **Logo empilhada**: aplicações verticais/quadradas.
- **Símbolo isolado**: ícones, marca d'água e aplicações pequenas.
- **Avatar round light/espresso**: WhatsApp, Instagram, LinkedIn e foto de perfil.
- **favicon.ico + PNGs + webmanifest**: pacote pronto para site.

## Formatos
- **SVG**: vetor escalável. As formas do logotipo e da tipografia foram convertidas em contornos, portanto não dependem de arquivos de fonte.
- **PNG**: fundo transparente, salvo em alta resolução (exceto favicons, que possuem tamanhos específicos).
- **ICO**: 16/32/48 px no mesmo arquivo.

## Observação técnica
Os SVGs deste pack são vetores reconstruídos a partir da identidade visual aprovada nesta conversa. Estão adequados para web, social, apresentações e materiais gráficos comuns. Para fabricação de fachada, registro marcário ou produção industrial que exija geometria milimétrica, recomenda-se uma revisão final do master vetorial por designer antes do envio ao fornecedor.
